Changelog & Roadmap

NomaDim by Kacper / NomaDirection · last updated 2026-07-30

Released

Milestones ship in order; each is a self-contained release.

  • M0–M7 — core parametric CAD: sketching (solver-free, snap + numeric input), extrude / revolve / fillet / chamfer / shell / pattern / mirror / combine, timeline history, undo/redo, XML document format, STL & STEP export.
  • SVG / DXF import — reference geometry as assembly or split shapes, with selectable key points; real AutoCAD DXF support (BLOCK/INSERT resolution, bulge arcs, ellipses).
  • M8 — faster startup: gzip-compressed kernel delivery, lazy kernel boot, installable PWA.
  • M9 — GUI hardening: tools gray out with a reason when unavailable; descriptive tooltips with shortcuts everywhere.
  • M10 — marketing landing page separate from the app.
  • M11 — offline license keys: Ed25519-signed, verified in-browser, no runtime backend. Free tier watermarks STL; Pro unlocks exact STEP export.
  • M12 — trust & content: sample projects, legal pages, in-app support, opt-in error reporting.

Roadmap

Planned, in no committed order:

  • Fully trimmed OCCT kernel build (< 8 MB) for even faster loads.
  • 3MF export for color / multi-material printing.
  • Constraint solver (v2) — the data model is already constraint-ready.
  • Assembly / multi-part documents.
  • Additional import formats and measurement tooling.

Roadmap items are directional, not promises, and may change without notice.
